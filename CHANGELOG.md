
# CHANGELOG — StudyPack AI

This file records the major development changes made after Milestone 1.

## October 2026 — Prompt Development

- Developed the initial StudyPack AI prompt (V1).
- Created V2 with improved instructions and output structure.
- Developed V3 to improve source grounding and terminology preservation.
- Created V4 with a two-stage generation and review workflow.
- Saved prompt versions and experiment outputs for comparison.

## November 2026 — Application Development

- Implemented the Streamlit application using Python.
- Added support for pasted lecture notes and PDF uploads.
- Integrated PyMuPDF for PDF text extraction.
- Integrated the Gemini API using the Google GenAI SDK.
- Implemented the two-stage study-pack generation and review workflow.
- Added input validation for empty, short and excessively long inputs.
- Added Markdown output and download functionality.

## November 2026 — Testing and Deployment

- Tested the application with lecture notes from multiple academic subjects.
- Tested PDF text extraction and invalid-input scenarios.
- Identified limitations involving unsupported content, question-count consistency and scanned PDFs.
- Deployed the application using Streamlit Community Cloud.
- Published the project source code on GitHub.
- Added architecture, workflow and testing documentation.
- Prepared the Milestone 2 demonstration and supporting documentation.

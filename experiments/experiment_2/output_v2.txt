SECTION 1: SUMMARY
Machine learning is a subset of artificial intelligence focused on enabling computers to learn patterns from data. This field is categorized by the type of data used for training: supervised learning utilizes labelled datasets, whereas unsupervised learning identifies hidden patterns within unlabelled data. Furthermore, machine learning models are applied to predict discrete categories through classification or continuous numerical values through regression.

SECTION 2: KEY CONCEPTS
Machine Learning: A branch of artificial intelligence that allows computers to learn patterns from data.
Supervised Learning: A method of training models that uses labelled datasets.
Unsupervised Learning: A method of identifying hidden patterns in data that is unlabelled.
Classification: A process used to predict discrete categories.
Regression: A process used to predict continuous numerical values.

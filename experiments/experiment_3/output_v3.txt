StudyPack AI: Machine Learning Basics
SECTION 1: SUMMARY
Machine learning, a subset of artificial intelligence, focuses on enabling computers to learn patterns from data. This field is divided into supervised learning, which utilizes labelled datasets for model training, and unsupervised learning, which detects hidden patterns within unlabelled data. Within supervised learning, tasks are categorized into classification, which predicts discrete categories, and regression, which predicts continuous numerical values.

SECTION 2: KEY CONCEPTS
Machine Learning: A branch of artificial intelligence that allows computers to learn patterns from data.
Supervised Learning: A type of learning that uses labelled datasets to train models.
Unsupervised Learning: A type of learning that identifies hidden patterns within unlabelled data.
Classification: A process that predicts discrete categories.
Regression: A process that predicts continuous numerical values.

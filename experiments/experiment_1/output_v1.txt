📚 Study Pack: Introduction to Machine Learning
1. SUMMARY
Machine learning is a subset of artificial intelligence focused on teaching computers to recognize patterns within data. The field is primarily categorized into supervised learning, which utilizes labelled data for training, and unsupervised learning, which uncovers hidden structures in unlabelled data. Furthermore, machine learning models are tasked with either classification (predicting discrete categories) or regression (predicting continuous numerical values).

2. KEY CONCEPTS
Machine Learning (ML): A branch of artificial intelligence where computers are programmed to learn and identify patterns from data rather than following rigid, pre-defined rules.
Supervised Learning: A training method that relies on "labelled" data (data that already contains the answers or target outputs) to teach a model.
Unsupervised Learning: A training method used to analyze unlabelled data to find hidden patterns or structures without prior guidance.
Classification: A type of predictive task where the model categorizes data into distinct, discrete groups or labels (e.g., "Yes/No" or "Type A/Type B").
Regression: A type of predictive task where the model forecasts a continuous numerical value (e.g., predicting a price or a temperature).

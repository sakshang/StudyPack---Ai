
Database Management System (DBMS)

A Database Management System is software used to store, organize, manage, and retrieve data efficiently. It provides an interface between users and databases.

A database is an organized collection of related information. Data is commonly stored in tables consisting of rows and columns.

A primary key is an attribute that uniquely identifies each record in a table. A foreign key is an attribute that establishes a relationship between two tables by referring to the primary key of another table.

SQL (Structured Query Language) is used to interact with relational databases.

Common SQL commands include:
1. CREATE – Creates database objects such as tables.
2. INSERT – Adds new records.
3. SELECT – Retrieves records.
4. UPDATE – Modifies existing records.
5. DELETE – Removes records.

Database normalization is the process of organizing data to reduce redundancy and improve data integrity. Common normal forms include First Normal Form (1NF), Second Normal Form (2NF), and Third Normal Form (3NF).
